# Тридевятое царство

Визуальная новелла по мотивам русских народных сказок: Иван-царевич, Василиса Премудрая,
Кощей Бессмертный, Баба-Яга, Серый Волк, Жар-птица и звери-помощники.

Один файл `index.html`, без сборки и картинок — вся графика нарисована в SVG.
Работает в браузере и как Telegram WebApp. Прогресс и открытые концовки сохраняются в `localStorage`.

- Тап / пробел / Enter — дальше, Esc — меню.
- 6 концовок, ветвления зависят от выборов (доброта к зверям, вежливость с Ягой, выбор у камня и т.д.).
- Сценарий — объект `SC` в `index.html`; формат шагов описан в комментарии над ним.
- Для отладки можно открыть сцену напрямую: `index.html?scene=oak&f={"wolf":1}`.
